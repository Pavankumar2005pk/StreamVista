# 🎬 StreamVista

A modern, responsive movie discovery application built with React that helps you explore trending, popular, and upcoming movies.

## ✨ Features

- 🎥 Browse trending, popular, and upcoming movies
- 🔍 Search for your favorite movies
- 🎞️ View movie details and trailers
- 🎨 Sleek, responsive UI with smooth animations
- ⚡ Fast and performant with React

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher) or yarn
- TMDB API key (free)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Pavankumar2005pk/StreamVista.git
   cd StreamVista/streamvista
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn
   ```

3. **Set up environment variables**
   Create a `.env` file in the root directory:
   ```env
   REACT_APP_TMDB_BEARER=your_tmdb_api_key_here
   ```
   > Get your free API key from [TMDB](https://www.themoviedb.org/settings/api)

4. **Start the development server**
   ```bash
   npm start
   # or
   yarn start
   ```
   The app will be available at [http://localhost:3000](http://localhost:3000)
